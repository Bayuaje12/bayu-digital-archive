[INDEX.03 / SYSTEMS ARCHITECTURE]

Metodologi dan Standar Rekayasa

Pendekatan rasional terhadap rekayasa digital: memprioritaskan semantik standar web terbuka di atas ketergantungan perangkat lunak yang berumur pendek.

PRINSIP.01

Semantik Standar dan Aksesibilitas Teruji

Setiap komponen interaktif dibangun menggunakan elemen bawaan peramban seperti button, a, dan table sebelum menambahkan layer script. Hal ini menjamin navigasi pembaca layar, pengoperasian papan ketik penuh, dan navigasi ramah fokus tanpa peretasan tambahan.

  • Kontras teks terverifikasi WCAG AA (minimal 4.5:1 untuk teks normal).
  • Dukungan navigasi tombol Tab, Enter, dan penutupan laci via Escape.
  • Target sentuh minimal 44x44 piksel pada seluruh layar sentuh mobile.
PRINSIP.02

Ketahanan Terhadap Hambatan Jaringan

Sistem tidak boleh gagal total ketika jaringan internet pengguna melambat atau terputus. Antarmuka tetap menyajikan konten utama dan hierarki informasi melalui berkas HTML murni yang dapat diproses langsung oleh browser.

  • Beban transfer halaman awal dikontrol secara ketat.
  • Tanpa pustaka font eksternal berbobot megabyte yang menghalangi rendering pertama.
  • Dukungan cache peramban lokal dan pemanfaatan penyimpanan terstruktur.

[INDEX.04 / COLOPHON]

Kolofon dan Spesifikasi Situs

Transparansi penuh mengenai instrumen, tipografi, dan parameter penyusunan portofolio arsip ini.

PILIHAN TIPOGRAFI

Situs ini dirancang menggunakan Plus Jakarta Sans sebagai rupa huruf utama dan IBM Plex Mono untuk penandaan metadata arsip serta data tabular teknis. Dipilih atas dasar keterbacaan tinggi dan proporsi geometris modern yang seimbang.

TEORI WARNA ARSIP

Dua skema warna diskalakan secara manual: Obsidian Dark (tinta arang mendalam) untuk kondisi pencahayaan rendah, dan Archival Linen (kertas arsip hangat) untuk mode terang. Warna aksen Vermilion Stamp dialokasikan secara hemat khusus untuk status fungsional.

INFRASTRUKTUR PENERBITAN

Diterbitkan secara statis tanpa proses kompilasi sisi server yang rumit. Berkas langsung disajikan melalui jaringan CDN GitHub Pages untuk keandalan maksimal dan efisiensi konsumsi daya komputasi.
