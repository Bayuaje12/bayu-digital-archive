# ARSIP DIGITAL BAYU : PORTOFOLIO DESIGN TECHNOLOGIST

Repositori ini memuat kode sumber arsip portofolio digital independen untuk Bayu, seorang Design Technologist dan Digital Archivist berbasis di Jakarta.

## Prinsip dan Arah Desain
- **Konsep:** Digital Ledger & Curated Museum Register (bukan halaman marketing atau template umum).
- **Rasio Energi & Gerakan:** ENERGY 2 / RHYTHM 3 / MOTION 1.
- **Dua Tema:** *Obsidian Dark* (default) dan *Archival Linen* (terang) dengan pemenuhan standar kontras WCAG 2.1 AA.
- **Tipografi:** Plus Jakarta Sans untuk teks editorial dan IBM Plex Mono untuk penomoran data teknis.
- **Nol Ketergantungan Eksternal:** Berjalan langsung di peramban tanpa build step atau framework compiler.

## Struktur Berkas
- `index.html`: Dokumen markup semantik dengan penandaan landmark, tabel arsip, dan form pesan interaktif.
- `css/style.css`: Lembar gaya terstruktur dengan variabel CSS, tata letak responsif bertahap, dan kepatuhan preferensi reduced-motion.
- `js/main.js`: Logika peralihan tema, laci navigasi, filter kategori arsip, dan validasi form lokal.

## Penerbitan
Situs ini dapat dijalankan langsung dengan membuka berkas `index.html` pada peramban web modern atau disajikan melalui GitHub Pages.
